# PDF 編輯器（macOS）

以 Swift、SwiftUI 與 Apple 原生 PDFKit 開發的 macOS PDF 編輯程式，介面為繁體中文，所有處理都在本機完成，不會上傳任何檔案。

- 系統需求：macOS 13 Ventura 以上（Apple Silicon 與 Intel 皆可）
- 不需要安裝任何第三方套件
- Windows 版請見 [PDFEditorWindows](../PDFEditorWindows/README.md)

## 功能

| 分類 | 功能 |
|---|---|
| 檢視 | 多分頁開啟多份文件、縮圖側欄、書籤（大綱）、放大縮小／符合視窗、單頁／連續／雙頁／書本模式、水平捲動、全文搜尋與結果標示、前往指定頁、深色模式 |
| 註解 | 螢光筆、底線、刪除線、便利貼、文字方塊（可選字型、樣式、字級、顏色並即時預覽）、手繪、矩形、橢圓、直線、箭頭；可自訂顏色、線寬、字級、填色；拖曳移動、雙擊編輯文字、Delete 鍵刪除、橡皮擦；註解清單面板 |
| 編輯 | **直接修改頁面上原有的文字**（原文真正移除、以相近字型寫在原位）、插入圖片、手寫簽名（可儲存多組常用簽名或匯入簽名圖檔）、白底遮蓋、塗黑遮蓋（永久移除底下內容）、文字浮水印、頁碼與頁首頁尾 |
| 頁面 | 拖曳縮圖重新排序、旋轉、刪除、複製、插入空白頁、從其他 PDF 插入頁面、擷取頁面為新檔、合併多份 PDF、依頁數或頁碼範圍分割 |
| 表單 | 直接在頁面上填寫 PDF 表單欄位；平面化所有註解與表單 |
| 轉換 | 匯出為 PNG／JPEG（72–600 dpi）、匯出純文字、從圖片建立 PDF、OCR 文字辨識（支援繁中、簡中、英文、日文），讓掃描檔可搜尋、可選取 |
| 安全 | 設定開啟密碼與擁有者密碼（加密）、開啟受密碼保護的檔案、移除密碼、匯出壓縮版本 |
| 其他 | 完整復原／重做、列印、最近開啟的檔案、拖放開啟 PDF 或圖片、未儲存變更提醒 |

## 安裝

### 方式一：下載編譯好的 DMG

每次推送到 GitHub 後，GitHub Actions 會在 macOS 上自動編譯、執行測試並產生 `PDFEditor.dmg`：

1. 到 repo 的 **Actions** 頁面，點選最新一次的「PDF 編輯器（macOS）」執行紀錄。
2. 在頁面下方的 **Artifacts** 下載 `PDFEditor-macOS`，解壓縮後打開 `PDFEditor.dmg`。
3. 將 **PDFEditor.app** 拖曳到「應用程式」資料夾。
4. 程式沒有經過 Apple 公證，第一次開啟時請在 App 上**按右鍵 → 打開**，再按一次「打開」。
   若仍被阻擋，到「系統設定 → 隱私權與安全性」下方按「強制打開」。

### 方式二：自行編譯

需要 Xcode 15 以上（或 Command Line Tools）：

```bash
cd PDFEditor
swift run                      # 直接執行
swift test                     # 執行單元測試
./scripts/build-app.sh 1.0.0   # 打包成 build/PDFEditor.app 與 build/PDFEditor.dmg
```

也可以用 Xcode 開啟 `PDFEditor/Package.swift`，選擇 `PDFEditor` scheme 後按執行。

## 使用說明

### 常用快捷鍵

| 動作 | 快捷鍵 |
|---|---|
| 開啟／新增空白文件 | ⌘O／⌘N |
| 儲存／另存新檔 | ⌘S／⇧⌘S |
| 關閉分頁 | ⇧⌘W |
| 復原／重做 | ⌘Z／⇧⌘Z |
| 尋找／下一個／上一個 | ⌘F／⌘G／⇧⌘G |
| 放大／縮小／實際大小／符合視窗 | ⌘=／⌘-／⌘0／⌘9 |
| 向右／向左旋轉頁面 | ⌘R／⌘L |
| 插入空白頁／刪除頁面 | ⇧⌘N／⌘⌫ |
| 新增書籤 | ⌘D |
| 前往頁面 | ⌥⌘J |
| 顯示／隱藏側欄 | ⌃⌘S |

### 工具快捷鍵（⌥⌘ + 字母）

選取 V、編輯文字 G、螢光筆 Y、底線 U、刪除線 K、便利貼 N、文字方塊 B、手繪 P、矩形 R、橢圓 O、直線 L、箭頭 A、白底遮蓋 I、塗黑遮蓋 X、橡皮擦 E。
在頁面上按 Esc 可切回選取工具。

### 小技巧

- **頁面操作**：在縮圖側欄可按住 ⌘ 或 ⇧ 多選頁面，再用右鍵選單或「頁面」選單一次處理；直接拖曳縮圖即可重新排序。
- **修改原有文字**：選「編輯文字」工具（⌥⌘G），點一下頁面上的文字，直接在原位修改後按 Return／Enter 套用、Esc 取消。原本的字會從頁面內容中真正移除（背景、圖片、線條保留），新文字以相同字級、顏色與相近字型（襯線／無襯線／等寬、粗體／斜體）寫在同一條基線上，可復原。一次編輯一行；原文若使用特殊或內嵌字型，新文字會以最接近的標準字型呈現。
- **遮蓋機密資料**：用「塗黑遮蓋」框選區域後，執行「工具 ▸ 套用遮蓋」。受影響的頁面會轉成圖片，底下的文字與圖形會真正被移除（無法再復原取得），套用前請確認。
- **簽名**：第一次使用時在簽名板上書寫並按「儲存並使用」，之後即可直接從已儲存的簽名中選取；在簽名縮圖上按右鍵可刪除。
- **圖片、簽名、浮水印與頁碼**：儲存或匯出時會固定到頁面內容中（文字仍可搜尋），之後無法再以註解方式移動或刪除；在存檔前都可以自由調整或復原。
- **OCR**：「工具 ▸ 文字辨識」使用 macOS 內建的 Vision 引擎，在本機處理。辨識後頁面外觀不變，但可以搜尋、選取、複製文字。
- **密碼**：「檔案 ▸ 密碼保護」設定的密碼會在下次儲存時生效；開啟受保護的檔案後，存檔會沿用原本的開啟密碼，也可以在同一個視窗中移除密碼。

## 專案結構

```
PDFEditor/
├── Package.swift                   Swift Package 設定
├── Sources/
│   ├── PDFEditorCore/              與介面無關、可單元測試的核心功能
│   │   ├── PageOperations.swift    旋轉、插入、搬移、擷取、合併、分割、頁碼範圍解析
│   │   ├── PageRendering.swift     點陣化、向量重繪、平面化、遮蓋
│   │   ├── CustomAnnotations.swift 圖片／簽名、浮水印、頁碼、遮蓋標記
│   │   ├── OCRService.swift        Vision 文字辨識與隱形文字層
│   │   └── ExportService.swift     存檔、加密、壓縮、匯出圖片與文字
│   └── PDFEditor/                  macOS App（SwiftUI + AppKit）
│       ├── App/                    App 進入點、選單、分頁管理、對話框工具
│       ├── Document/               文件模型、復原紀錄、文件動作
│       ├── Views/                  主畫面、PDF 檢視器、側欄、工具列
│       ├── Tools/                  編輯工具狀態
│       └── Sheets/                 浮水印、頁碼、簽名、密碼、分割、匯出、OCR 對話框
├── Tests/PDFEditorCoreTests/       核心功能單元測試
├── Resources/Info.plist            App 套件資訊（檔案類型關聯）
└── scripts/
    ├── build-app.sh                打包 .app 與 .dmg
    └── make-icon.swift             產生 App 圖示
```

## 已知限制

- 直接編輯文字以「行」為單位，並以最接近的標準字型重寫該行；無法沿用原文件內嵌的特殊字型。
- 未經 Apple Developer ID 簽章與公證，首次開啟需手動允許。
- 擁有者密碼只作為加密金鑰，PDFKit 不提供細部權限（禁止列印、禁止複製等）的設定。

## 授權
