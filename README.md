# 當沖戰情室

台股現股當沖輔助工具。單一網頁＋一支只用 Python 標準函式庫的本機報價服務。

## 快速開始

```bash
python3 daytrade_server.py          # Windows：py daytrade_server.py
# 瀏覽器開啟 http://127.0.0.1:8787
```

`daytrade.html` 與 `daytrade_server.py` 需放在同一個資料夾。可用 `--port` 改埠號；預設只綁定 127.0.0.1。

## 功能

| 分頁 | 內容 |
|---|---|
| 即時盯盤（本機版） | 觀察清單、最佳五檔、內外盤力道、到價聲音與桌面通知、TradingView 嵌入圖表 |
| 進出場計算 | 升降單位與漲跌停、依風險 % 計算張數／零股、扣手續費與當沖證交稅後的淨損益、損益兩平檔數、價位階梯 |
| 盤中技術位 | 1 分 K 圖、VWAP ±1σ/±2σ、EMA9/21、開盤區間、CDP 與 Pivot、規則化訊號與多空判讀；本機版每 30 秒自動更新 |
| 交易日誌 | 勝率、盈虧比、期望值、獲利因子、最大回撤、R 倍數、依策略與情緒拆解、權益曲線、AI 教練（claude.ai 版） |
| 風控與紀律 | 單日虧損上限、筆數上限、連虧停手、獲利回吐保護、盤前檢查清單、平倉倒數 |

## 報價來源

- 即時成交與五檔：證交所基本市況報導 `mis.twse.com.tw`（快取 3 秒，請勿調更短，以免 IP 被暫時封鎖）
- 分 K 與昨日高低收：Yahoo Finance chart API；失敗時改用本機輪詢累積的分 K
- TradingView：僅使用官方嵌入圖表顯示，不抓取其資料

同一個 `daytrade.html` 也可發佈在 claude.ai，屆時為離線模式（無即時報價，日誌存於私人雲端並可用 AI 教練）。

## 注意

僅供計算與紀錄輔助，不構成投資建議。費率與規則以券商及證交所公告為準（現股當沖證交稅 0.15% 減半優惠實施至 2027/12/31）。
