# 檢核規則與指標總表

規則 = 指標算式 + 比較子 + 門檻。門檻本身可以是算式，並引用公司政策參數
（`policyEndorsementPct` 等由「設定」頁帶入），因此調整政策即調整門檻，無須改動程式。

- **紅線（FAIL）**：已違反，須立即依「觸發時應採行動」處理
- **黃燈（WARN）**：尚未違反但緩衝不足，屬預警
- **資料不足（NO_DATA）**：缺欄位或分母為零。此狀態一律**不得**視為通過，且在檢核總分中一樣扣分
